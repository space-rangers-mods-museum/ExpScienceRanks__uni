# 🪐 ExpScienceRanks

* **Name:** ExpScienceRanks
* **Author:** Huk, 100kg, uhanich, Catarsys, Klaxons

### Summary

Adds the ability to gain science titles and the unique Tick hull

---

## 📖 Description

Degrees based on science:

- Added science degrees that can be developed

- A panel has been added to the ship menu, which displays the scientific rank

- Equipment acrination and deacrination experiments, which can be accessed after gaining science ranks

- New unique "Tick" hull

- New "Tick" hull modes can be switched manually in ship menu
